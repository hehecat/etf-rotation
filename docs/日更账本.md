# 日更账本 (多年可回溯)

## 目的
把 GitHub Daily 从「当日快照」升级为可跨年回溯的有效收益账本, 供 3 个月/多年后做结构改进, 而不是凭全样本回测美化改参.

## 主文件 (入库)
| 文件 | 含义 |
|------|------|
| `output/risk_audit/daily_scorecard.jsonl` | **主账本**, 一日一行 |
| `output/risk_audit/daily_scorecard_latest.json` | 最新一行 |
| `output/action_history.jsonl` | 生产动作时间线 |
| `output/risk_audit/progress.jsonl` | 可判性推进 |
| `output/shadow_states/*.json` | 影子 `nav_history` / live |
| `output/ledger_summary.txt` | 人读汇总 |

## 记分卡字段 (schema=1)
- 主键: `date` = `market_asof` (交易日), **一日一行后写覆盖**
- 门控: `data_lag` / `thin_live` / `level` / `readable_yield`
- 有效收益: `live_return_pct` + `live_excess_pct` (仅 `readable_yield=true` 可解释)
- 生产: `prod.action` / `market_ok` / `holding`
- 研究: `signal_live` + `shadows[]`
- 决策: `next_action` / `decision`

## 命令
```bash
./etf history              # 汇总
./etf history --append     # 从当前产物写/覆盖今日行
./etf history --tail 20
./etf history --json
```

日更 pipeline 在 pulse 后自动 `ledger` 一步.

## 改进纪律
1. `DATA_LAG` / `THIN` / `readable_yield=false` → 不判策略好坏
2. 空仓 + 大盘跌且 xs>0 → 风控有效; 空仓 + 大盘涨且 xs<0 → 机会成本
3. **可读日 ≥ 60** 且 dual-end 门控仍过, 才讨论结构变更 (soft/dual_ma/宇宙)
4. 生产 C01 默认冻结; promote 只走研究影子

## 窗口
jsonl / nav_history 默认保留约 **2800** 个交易日 (~10 年), 超出滚动截断.
